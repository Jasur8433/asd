# KPI-Цифра ВУЗ

Статический веб-сайт с минимальными требованиями по внедрению KPI-системы для подразделений цифровизации в высших образовательных учреждениях.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.
