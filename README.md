# KPI Digital University

Полноценный минимально рабочий веб-прототип системы KPI для подразделений цифровизации в высшем образовательном учреждении.

## Что реализовано

- Dashboard с общим KPI, статусом, карточками и визуализацией по подразделениям.
- KPI-модуль: добавление/удаление показателей, веса, плановые значения.
- Сотрудники: роли (администратор, руководитель, сотрудник), подразделения.
- Результаты: ввод фактических значений и автоматический расчёт выполнения.
- Отчёты: сводная таблица, экспорт CSV (для Excel), печать в PDF через браузер.
- Админ-раздел с минимальными требованиями внедрения KPI.
- Сохранение данных в `localStorage` и тёмная/светлая тема.

## Запуск локально

```bash
python3 -m http.server 8000
```

Откройте в браузере: `http://localhost:8000`.
